
Visual Studio 2017 -msvc
------------------------------

cmake -B Build/msvc

^^inside the root folder with .git and .gitignore


-go into Build and open the ZombieGame.sln

-right click the ZombieGame project and Set Up as Startup Project
-start
or
- run: cmake --build . --config Release/Debug //(your choice)

Codeblocks -mingw
-----------------------------
->as the tutorial for the 2.6 SFML version says on the site, MINGW version 13.1.0 is required

-In order to not confuze build files, create a folder mingw inside a Build folder

-CMD into that folder (cd .path_to_folder)

-command: cmake -G "CodeBlocks - MinGW Makefiles" ../.. -D CMAKE_BUILD_TYPE=Debug

-Build from Codeblocks itself 
or
-call mingw32-make

--assets folder must also be moved to the bin folder of the mingw build



Linux

->unzip the zip folder inside SFML/linux
->run cmake from inside a build folder
->run make anywhere inside the project
-> ./ZombieGame

if some error regarding uiMainGame Header is present, theres a slight change in syntax between the include in the src file with the name of the include itself, match them and it should be good
